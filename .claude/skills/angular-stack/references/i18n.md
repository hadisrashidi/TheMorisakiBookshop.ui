# i18n & RTL/LTR Reference

## Defaults

- Default language: Persian (`fa`), RTL
- Stored in `localStorage` key: `app_language`
- Detection order: localStorage → browser → default (`fa`)

## LanguageService

```typescript
export class MyComponent {
  private readonly languageService = inject(LanguageService);

  switchLanguage(lang: 'fa' | 'en'): void {
    this.languageService.setLanguage(lang);
  }

  get isRTL(): boolean {
    return this.languageService.isRTL();
  }
}
```

## Translation Pipe

```html
<h1>{{ 'common.welcome' | translate }}</h1>
<p>{{ 'validation.minLength' | translate:{min: 5} }}</p>
```

Translation files: `public/i18n/fa.json` and `public/i18n/en.json`

```json
{
  "common": { "welcome": "خوش آمدید" },
  "auth": {},
  "validation": {},
  "messages": {}
}
```

## Direction-Aware SCSS

```scss
[dir='rtl'] .my-component {
  margin-right: var(--space-4);
  text-align: right;
}
[dir='ltr'] .my-component {
  margin-left: var(--space-4);
  text-align: left;
}
```

## Bootstrap RTL Utilities

```html
<div class="float-start">   <!-- right in RTL, left in LTR -->
<div class="ms-auto">       <!-- start margin auto -->
<div class="rounded-start"> <!-- rounded start corner -->
```

## Date Pickers

- Use `<app-persian-date-input>` for Jalali/Persian dates
- Use `<app-gregorian-date-input>` for Gregorian dates
- Both are in `core/components/date-pickers/`

## Input Restrictions

- `persianOnly` / `persianCharsOnly` / `persianNumbersOnly` directives
- `englishOnly` / `englishCharsOnly` / `englishNumbersOnly` directives
- Located in `core/components/directives/`
